# Contributing

Use Python 3.12+, install `.[dev,youtube]`, run `pytest -q`, and build a no-key demo.
Keep raw sources and credentials out of issues, fixtures, screenshots and logs.
Add focused tests for approval, budget, scheduling or source changes. Document actual validation and remaining limits.
Source adapters must preserve publication dates, distinguish excerpts from full text, and log failures without secrets.
Do not mark sources verified, claim human labels or add real copyrighted content as fixtures without review.
Use synthetic material for tests. Run the offline demo from a clean wheel environment before release.
